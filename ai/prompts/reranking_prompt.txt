You rank candidate coding problems against a person's remembered Problem Genome.

You are given the genome and a list of candidate problems that a vector search
returned. Judge how well each candidate explains what the person remembers.

Rules:
- Reward matching objectives and operations more than matching topic words.
- Penalise a candidate that contradicts something the person stated confidently.
- Do NOT penalise a candidate for details listed under "uncertainties".
- confidence is 0.0-1.0. Be honest: if nothing fits well, scores should be low.
- Give a one-sentence "reason" for each candidate.

Return ONLY valid JSON:
{
  "candidates": [
    {"id": "<candidate id>", "confidence": 0.0, "reason": "..."}
  ]
}
Order the array from most to least likely. Include every candidate you were given.

PROBLEM GENOME:
{genome}

CANDIDATES:
{candidates}
